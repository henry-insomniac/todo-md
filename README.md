# Todo MD

[官网与下载](https://henry-insomniac.github.io/todo-md/)

Todo MD 是一个原生 macOS 应用，将待办、Markdown 阅读与编写、轻量进度放在一起。支持 macOS 14+、Apple Silicon 与 Intel。

## 下载

在 [Releases](https://github.com/henry-insomniac/todo-md/releases) 下载已签名并经 Apple 公证的 DMG，打开后将 Todo MD 拖入 Applications。

## 此仓库的用途

这里只保存官网静态页面和公开展示图片。Releases 提供编译后的安装包、ZIP 和 SHA-256 校验文件。应用源码不在此仓库公开。

页面无第三方脚本、字体 CDN、分析追踪或前端框架。截图来自独立演示数据；界面图用于产品展示，不能直接在网页里编辑任务。

视觉排版参考 [Things](https://culturedcode.com/things/) 与 [Bear](https://bear.app/)，未使用它们的品牌或图片资产。

问题反馈请使用 [Issues](https://github.com/henry-insomniac/todo-md/issues)，请勿附上密码或私人文档。
